# ZENのProspector対応設計

## 目的と対象

標準Prospectorを親機として、ZEN左右のキーと右PMW3610トラックボールを
USB接続したMacへ送る追加構成を用意する。画面には現在のレイヤー番号と
左右の電池残量・接続状態を表示する。

ユーザーはこの接続構成の対応を希望している。初回対象を標準Prospector
（Seeed XIAO nRF52840＋1.69インチST7789系LCD）、右PMW3610、左通常キーと
する。標準Prospectorを使うことはユーザー回答で確認済み。

## 現状と制約

- 現在は右ZENが親機、左ZENが子機。Prospector用のビルドはない。
- ZMKはE24-GHの`v0.3-zen`。分割子機の広告開始を再試行する修正を保持する。
- Prospector公式モジュールのv0.3対応版を利用し、
  `77a852293532879c992847e01db27abe4f94fa9f`に固定する。
- 既存の通常版・診断版・他センサー版のビルドと動作設定を保つ。
- CPIは400、方向は現行版と同じ。右端列の配線・キー割当は変更しない。
- マウスレイヤー1の500ms維持、打鍵後200msの誤発動抑制、
  スクロールレイヤー4と現行倍率を親機側でも維持する。
- 接触不良や電池のみでの起動不良の修理は、この機能追加に含めない。

## 検討した方法

1. **現在のv0.3-zenにドングル構成を追加する（提案）。**
   既存の通常版を残し、既に存在する分割入力転送と物理レイアウトを再利用できる。
2. ZMK/Zephyr全体を更新してProspectorの新しい画面実装へ移行する。
   センサードライバー・BMP Boost等の移植を伴い、この対応には変更範囲が大きい。

現在の目的には1が適切。通常版を維持して追加構成を用意する方針を提案する。

## 構成

```text
左ZEN（既存の子機ファーム） ─┐
                            ├─ BLE → Prospector（親機） → USB → Mac
右ZEN（PMW3610子機ファーム） ─┘
```

- 左手には既存の`zen_left_peripheral.uf2`を使用する。
- 右手用に`zen_right_trackball_pmw3610_peripheral.uf2`を追加する。
  センサーの生の相対移動イベントを、既存の`zmk,input-split`で転送する。
  右手の子機構成ではローカルのポインター処理・Studio親機機能を使わない。
- `zen_dongle`シールドと、標準Prospector用のビルドを追加する。
  右トラックボールの方向変換・自動マウスレイヤー・スクロール処理は
  Prospectorで1回だけ行う。二重変換やトラックパッド用の倍率の混入を避ける。
- 左右とドングルが同一のマトリクス変換・物理レイアウトを参照するよう、
  必要な定義だけを共通ファイルに分離する。BMP専用GPIOや電池ドライバーは
  ドングルに取り込まない。
- ProspectorにZMK StudioのUSB接続を用意し、同じキーマップを編集できる構成を目指す。
  画面とのメモリー共存をビルドで検証し、入らない場合に黙って機能を落とさない。
- 初期版は固定輝度50で、照度センサーとタッチ操作には依存しない。
  レイヤー名の追加編集は行わず、モジュールの既定どおり番号表示を利用する。
- Prospector用の設定リセットUF2も追加する。既存BMP Boost用リセットは維持する。

## 実装側に任せる事項

追加snippetと共通ファイルの名前、追加モジュールの固定コミット、RAMに収めるための
バッファ・スタックサイズの必要最小限の調整。右の入力チャネルは既存の0を再利用し、
既存左センサーの10〜12とは衝突させない。

## 確認方法と完了の区別

1. Prospector親機、右PMW3610子機、Prospectorリセットの実ビルドを通す。
2. 既存の通常版・左子機・診断版等のビルドを通し、生成された設定を比較する。
3. 生成DTS/Kconfigで、親機の子機数2、共有キー配置、子機の右列オフセット、
   入力転送の接続先、400CPI、方向とスクロール処理、200ms抑制、Studio、画面を確認する。
4. UF2の生成・基本形式と、ビルド時のメモリー使用量を確認する。
5. READMEに対象機器、各UF2の用途、左右とドングルの設定リセットが保存済み
   ペアリング情報・Studio設定を消すこと、左→右のペアリング順、通常版への復帰手順を書く。
   文書化のみで、実機の消去や書き込みは自動実行しない。
6. 実機では左右入力、右端4キー、トラックボールの上下左右、クリックとスクロール、
   マウスレイヤー、電池表示、再接続、Studio接続を確認する。

ファームのビルド・設定検証と、実機の動作確認は別に報告する。Prospectorが未入手なら
実機確認は未実施として残し、対応済み・動作保証済みとは扱わない。

## 接続上の変更

この追加構成では左右ともProspectorに接続するため、ProspectorなしではMacへ直接接続できない。
元の右親機ファームを残し、設定リセットと再書き込みで従来構成へ戻せるようにする。
